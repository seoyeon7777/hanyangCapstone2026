# 의류 3D 피팅 파이프라인 — 설계·모듈 종합 보고서

**프로젝트:** hanyangCapstone2026  
**전략:** Hybrid P0 (Template Morph) + P1 (Silhouette) + P2 (Neural Contract)  
**기준일:** 2026-08-10  
**진행률:** A 100% / B 100% / C ≈93% / 전체 ≈99% (엔지니어링)

---

## 1. 프로젝트 목표

**입력:** 옷 사진(정면 필수, 측면/후면 선택) + 치수(cm) + (선택) 원단·체형  
**출력:** 치수가 반영된 3D 의류 메쉬(OBJ/GLB) + 아바타 피팅 + QA 리포트 + (선택) 렌더

순수 “사진 1장 → 완전 신규 3D 옷”은 아직 불안정하므로,  
**템플릿 Shape Key + Blender**를 코어로 두고 이미지 이해·실루엣·neural 계약을 단계적으로 붙이는 **Hybrid** 전략을 사용한다.

---

## 2. 로드맵 (P0 / P1 / P2)

| Phase | 이름 | 하는 일 | 상태 |
|-------|------|---------|------|
| **P0** | Template Morph + Texture | 치수→Shape Key, 분류, 캘리브, 텍스처, Cloth Sim | 제품 기본 경로 (완료) |
| **P1** | Silhouette-guided Deform | 마스크 기반 외곽/깊이 보정 | 완료 (실사진 마스크는 외부) |
| **P2** | Neural Reconstruction | synthetic/ONNX/torch 계약 + ICP retarget | ≈93% (학습 가중치는 외부) |

---

## 3. 전체 아키텍처

```
[Web UI / API] Flask (app.py)
       │
       ▼
[Job Queue] services/worker_queue.py + job_store.py
       │
       ▼
[Orchestrator] pipeline/orchestrator.py
  ingest → understand → fabric → template_match → measure_fusion
  → calibrate → neural_reconstruct → silhouette_deform
  → geometry_fit → qa
       │
       ├─ models/          (치수·실루엣·메쉬 QA)
       ├─ pipeline/adapters/ (분류·OCR·neural·Blender)
       └─ services/blender_runner.py → blender/*.py (Blender 4.4)
```

## 4. 파이프라인 스테이지 상세

| # | 스테이지 | 모듈 | 역할 |
|---|---------|------|------|
| 1 | ingest | `pipeline/stages/ingest.py` | 이미지·JSON → JobManifest 정규화 |
| 2 | understand | `pipeline/stages/understand.py` | rembg 배경제거, 의류 분류, (선택) OCR |
| 3 | fabric | `pipeline/stages/fabric_resolve.py` | 원단 비율 → 탄성/굽힘 물성 |
| 4 | template_match | `pipeline/stages/template_match.py` | 카탈로그 blend + 아바타 S/M/L |
| 5 | measure_fusion | `pipeline/stages/measure_fusion.py` | 사용자 치수 > OCR > 추정 병합 |
| 6 | calibrate | `pipeline/stages/calibrate.py` | export→재측정→Shape Key 보정 루프 |
| 7 | neural_reconstruct | `pipeline/stages/neural_reconstruct.py` | P2: neural 메쉬 + ICP retarget |
| 8 | silhouette_deform | `pipeline/stages/silhouette_deform.py` | P1: 실루엣 X/Z 변형 |
| 9 | geometry_fit | `pipeline/stages/geometry.py` | 텍스처 bake + Blender export/sim/render |
| 10 | qa | `pipeline/stages/qa.py` | 캘리브 오차·메쉬·neural 품질 게이트 |

## 5. 모듈별 설명

### 5.1 `pipeline/` — 오케스트레이션·어댑터
| 모듈 | 용도 |
|------|------|
| `orchestrator.py` | 스테이지 순서 실행, QA 실패 시 캘리브 재시도 |
| `schemas/manifest.py` | JobManifest / Options (phase P0/P1/P2) |
| `adapters/catalog.py` | garment_catalog.json 매칭 |
| `adapters/garment_classifier.py` | 합성 특징 기반 의류 분류 + 가중치 |
| `adapters/vision_adapter.py` | rembg 등 비전 전처리 |
| `adapters/ocr_adapter.py` | pytesseract 치수 OCR 후보 |
| `adapters/neural_adapter.py` | reconstruct / retarget (icp_morph 등) |
| `adapters/neural_backends/onnx_backend.py` | ONNX Runtime InferenceSession |
| `adapters/neural_backends/torch_backend.py` | TorchScript (가중치 없으면 skip) |
| `adapters/blender_adapter.py` | Blender runner 호출 래퍼 |
| `eval/runner.py` | 정확도 벤치 케이스 실행 |

### 5.2 `models/` — 기하·치수·품질
| 모듈 | 용도 |
|------|------|
| `fitting_model.py` | 치수 cm → Shape Key(-1~1), 아바타 매칭, 원단 탄성 |
| `garment_measure.py` | OBJ 버텍스 → 라벨 cm 재측정 |
| `calibrate_shape_keys.py` | 목표 cm까지 반복 보정 |
| `silhouette_deform.py` | 전면/측면 마스크로 X·Z 변형, bipodal pants |
| `fabric.py` | 원단 정규화 |
| `mesh_qa.py` | NaN/AABB/퇴화면/토폴로지 검사 |

### 5.3 `services/` — 런타임·운영
| 모듈 | 용도 |
|------|------|
| `blender_runner.py` | export → simulate → texture GLB → render 조율 |
| `job_store.py` | 잡 결과 JSON 저장 |
| `worker_queue.py` | 디스크 큐 (pending/running/failed) |
| `ops_snapshot.py` | /ops 대시보드 스냅샷·진행률 |
| `alerts.py` | 큐/벤치/field_tape 알림 |

### 5.4 `blender/` — Blender 스크립트 (외부 프로세스)
| 스크립트 | 용도 |
|----------|------|
| `export_cloth.py` | Shape Key 적용 → cloth_shaped.obj |
| `simulate_cloth.py` | Cloth + Collision 피팅·압력 |
| `apply_texture.py` | 멀티뷰 albedo → cloth_textured.glb |
| `script.py` | 4뷰 실루엣 렌더 |
| `create_garment_templates.py` | pants/skirt 생성, hoodie/jacket 클론 |
| `config.py` | BLENDER_PATH, BASE_DIR |

### 5.5 `assets/` — 데이터 자산
| 경로 | 내용 |
|------|------|
| `clothing/cloth_*.blend` | top, hoodie, jacket, pants, skirt 템플릿 |
| `clothing/garment_catalog.json` | 별칭·측정키·nearest 노트 |
| `clothing/classifier_weights.json` | 분류기 가중치 + holdout 메타 |
| `avatars/body_{S,M,L}.blend` | 아바타 |
| `neural/synthetic_contract.onnx` | P2 계약용 fixture (**학습 모델 아님**) |

## 6. 사용 기술 스택 (무엇을 왜 쓰는지)

| 기술 | 역할 |
|------|------|
| **Python 3.11** | 전체 백엔드·파이프라인 |
| **Flask / flask-cors** | REST API·웹 UI·SSE 진행률 |
| **NumPy / SciPy** | 메쉬·실루엣·ICP·통계 |
| **Pillow** | 이미지 로드·합성 픽스처·텍스처 |
| **rembg** | 배경 제거(세그멘테이션 근사) |
| **onnxruntime** | P2 ONNX 추론 계약 |
| **pytesseract** | 라벨 OCR 치수 후보 |
| **Blender 4.4** | Shape Key export, Cloth Sim, GLB, 렌더 |
| **unittest + GitHub Actions** | 회귀 테스트·CPU 벤치 |

선택/주입: **Torch** (가중치 있을 때만), **ONNX 파일 fixture** (결정적 Constant 그래프).

## 7. API·사용자 흐름

1. `POST /api/pipeline/run` — 이미지 + 치수 JSON 업로드  
2. 잡 큐/스레드에서 `run_pipeline()` 실행  
3. `GET /api/fit/progress/<job_id>` (SSE) 또는 poll  
4. `GET /api/pipeline/result/<job_id>` — OBJ/GLB·QA  
5. `/ops` — 헬스·큐·벤치·진행률

기타: `/api/health`, `/api/pipeline/queue`, `/api/pipeline/retry/<id>`

## 9. Neural (P2) 백엔드

| 백엔드 | 설명 |
|--------|------|
| stub | 스킵 → 템플릿 유지 |
| synthetic | 의류별 결정적 closed mesh (테스트용) |
| onnx | InferenceSession + fixture ONNX |
| torch | TorchScript / inject (없으면 skip) |

Retarget: `passthrough` | `vertex_morph` | **`icp_morph`** (P2 기본)

# 바이브 코딩 시작 가이드 (C 파트)

## 1. 준비
1. 저장소를 받고 `recommend` 폴더로 이동해요.
2. `python test_feed.py`를 실행해서 `9/9 통과`가 나오는지 확인해요.
3. `python feed.py`를 실행해요. 스트레이트 사용자 점수표가 나와야 해요.
   칼라 셔츠, 센터프레스 슬랙스, H라인 스커트는 위쪽에 있고, 러플·오버사이즈·하이넥·패딩은 "제외"로 나오면 정상이에요.

## 2. AI에게 보낼 첫 메시지 (그대로 복사)

```
CLAUDE.md를 먼저 끝까지 읽어 줘.
9번 체크리스트에서 다음 단계 하나만 진행해 줘.
명세는 4장을 따르고, 3장 함수 모양은 바꾸지 마.
그 단계의 정답 테스트를 손으로 계산해서 test_feed.py에 추가하고,
python test_feed.py가 전부 통과하면 체크리스트를 갱신해 줘.
마지막에 새로 만든 함수가 무슨 일을 하는지 쉬운 말로 3줄로 설명해 줘.
```

## 3. 단계마다 확인할 3가지
1. `python test_feed.py`를 직접 돌렸을 때 전부 통과했나요?
2. 기존 테스트의 정답값(0.785, 0.48125, 0.91)이 바뀌지 않았나요?
3. `CLAUDE.md` 9번 체크리스트에 체크가 하나 늘었나요?

셋 다 "예"면 다음 메시지는 "다음 단계"라고만 보내도 돼요.

## 4. 막혔을 때 할 말
- 테스트가 깨졌을 때: "테스트가 깨졌어. 정답값은 바꾸지 말고 코드를 고쳐 줘."
- AI가 함수 모양을 바꾸려 할 때: "CLAUDE.md 3장 약속대로 해 줘."
- 대화가 길어졌을 때: 새 대화를 열고 2번 첫 메시지를 다시 보내요. 체크리스트 덕분에 이어서 진행돼요.

## 5. 발표 전에 꼭 이해할 함수 3개
- `final_score`: 체형 60% + 취향 25% + 시즌·인기 15%로 옷 하나의 점수를 매겨요. 단일형인데 피해야 할 옷이면 0점(제외)이에요.
- `rank`: 점수순으로 줄 세우되, 같은 종류 옷이 너무 몰리지 않게 섞어요.
- `home_feed`: 홈 화면에 "오늘의 추천", 카테고리별 추천, 추천 코디를 묶어 보여 줘요.
